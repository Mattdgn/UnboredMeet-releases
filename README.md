# UnboredMeet downloads

Official macOS beta installers and automatic update metadata for [UnboredMeet](https://unboredmeet.com).

Apple silicon · macOS 14.2 or newer.

Signed and notarized installers will appear under Releases. The beta/current.json manifest selects the beta used by the website and Sparkle updater.

This repository contains distribution files only, not the application source code. No beta is published yet.
